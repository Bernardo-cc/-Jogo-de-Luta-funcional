# 🎮 Jogo de Luta Funcional

Um jogo de luta desenvolvido com **HTML, CSS e JavaScript**, criado como projeto de estudo para praticar lógica de programação e desenvolvimento web.

## 📌 Sobre o projeto

O jogo simula uma batalha entre dois personagens. Cada personagem possui atributos próprios, como vida, ataque e defesa.

Durante a batalha, os jogadores podem atacar, causar dano e acompanhar a evolução da luta por meio das barras de vida e do registro de eventos.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ⚔️ Funcionalidades

- Criação de diferentes personagens e monstros.
- Atributos de vida, ataque e defesa.
- Sistema de combate com cálculo de dano.
- Barras de vida atualizadas dinamicamente.
- Registro de mensagens durante a batalha.

## ▶️ Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Clique nos botões de ataque para jogar.

## 🎯 Objetivo

Praticar JavaScript, manipulação do DOM, eventos, objetos, funções e organização de código em diferentes arquivos.
